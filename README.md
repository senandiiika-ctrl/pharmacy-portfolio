# Adi Tri Wibowo — Pharmacy Portfolio

A responsive, single-page professional portfolio built with HTML, CSS, and vanilla JavaScript for GitHub Pages.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for the Pages deployment to complete.

Expected site URL: https://senandiiika-ctrl.github.io/pharmacy-portfolio/

## Personalise
- Update the content in `index.html` when new verified information is available.
- Add a profile image under `assets/images/` if desired. The current hero uses a typographic monogram so the site does not display a missing-image placeholder.
- Add a CV PDF only after confirming the exact version intended for public access.
- The contact email and LinkedIn URL are already configured.

## Notes
Content is based on the latest ATS CV supplied for this portfolio. No private LinkedIn attachments, certificates, or profile images have been copied. The design uses Google Fonts (DM Sans and Playfair Display); the site remains readable with system fallback fonts if Google Fonts are unavailable.
